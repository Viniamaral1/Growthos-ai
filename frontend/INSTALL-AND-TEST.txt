What this version changes

Executive Team
- "Important only" no longer suggests capture for greetings, short replies, generic assistant introductions, or ordinary notes.
- "Everything" continues to suggest capture for every substantive assistant response.
- Manual Capture remains unchanged.
- The automatic suggestion stays available until Save, Change, Dismiss, composer interaction, Escape, or a newer assistant response.
- After 8 seconds it only dims; it does not disappear.
- Hover/focus restores full opacity.
- Confidence/context explanations use the app tooltip system instead of the browser's grey title tooltip.
- Adds a safe fallback so the assistant heading cannot render "GrowthOS undefined".

Knowledge
- Restores the project/subject sidebar as a compact icon rail when collapsed instead of removing it.
- Moves its collapse control onto the boundary between the project rail and the active Knowledge Space, so it is visually detached from the space header.
- Adds an independent Categories collapse control for All, Emails, Ideas, Research, Decisions, Strategy, Tasks and Notes.
- The two controls are independent: collapsing projects does not collapse categories, and vice versa.

Checks
1. Set Capture Suggestions to Important only.
2. Send "Hi". No automatic capture suggestion should appear.
3. Request a structured email, strategy, decision, research summary, action list, or similar durable output. A suggestion should appear.
4. Leave it untouched for 8 seconds. It should dim but remain present.
5. Hover it. It should return to full opacity.
6. Confirm the confidence/context tooltip is styled by the app rather than shown as a native grey rectangle.
7. In Knowledge, collapse the left project list. It should become a narrow icon rail and the main space should expand.
8. Separately collapse Categories. The All/Emails/etc. row should hide while the project rail remains unchanged.
