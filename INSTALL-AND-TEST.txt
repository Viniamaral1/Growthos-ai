INSTALL
Copy the three files into the matching paths in your GrowthOS project.
Stop the frontend, then from the project root run:

Remove-Item -Recurse -Force .\frontend\.next -ErrorAction SilentlyContinue
cd frontend
npm run dev

Hard-refresh the browser with Ctrl + Shift + R.

WHAT WAS ADDED
- A quiet, faded capture suggestion under the latest qualifying assistant response.
- Default preference: Important items only.
- Suggestions identify Email, Idea, Research, Decision, Strategy, Task, or Note.
- Existing Knowledge Space is suggested only when the message actually matches its name/words.
- Save: saves directly when a confident existing Space is found.
- Change: opens the existing Capture Knowledge dialog with type and Space pre-filled.
- Dismiss: removes the suggestion for that message during the current app session.
- Existing manual Capture button remains unchanged.
- Settings now includes Manual only / Important items only / Suggest everything.
- Knowledge Subjects sidebar can collapse to an icon rail and expand again.
