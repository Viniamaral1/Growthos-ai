GrowthOS — Chat Search Layout Fix

Replace this project file:
frontend/app/components/CofounderChat.tsx

Then from the project root:
1. Stop the frontend server.
2. Delete the Next.js cache:
   Remove-Item -Recurse -Force .\frontend\.next -ErrorAction SilentlyContinue
3. Start the frontend:
   cd frontend
   npm run dev
4. Hard refresh the browser with Ctrl + Shift + R.

Test only:
- Hover Search: navy tooltip appears below the button and is fully visible.
- Open Search: the normal chat composer is hidden.
- Search panel appears in the lower workspace area and does not sit behind the composer.
- Close Search by clicking outside or pressing Esc: the normal composer returns immediately.
- Existing search, Context, scrolling, Capture and routing still work.
