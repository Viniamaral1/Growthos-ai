GrowthOS AI v3.4.1 — Guided Research Discovery
Baseline: GrowthOS-AI-DEV(7).zip

WHAT THIS FIXES
- Research is now integrated into Executive Team chat instead of existing only on the Research page.
- Adds a visible “Explore an idea” control above the chat composer.
- Users can begin with a vague idea, opportunity, problem, or open question.
- No PDF, business plan, existing workspace profile, or finished idea is required.
- Automatic research-intent detection is conservative and topic-agnostic.
- Guided discovery creates a persistent Research Project in the active workspace.
- Natural-language replies are mapped to outstanding discovery questions.
- Once required context is collected, “Build the research plan” creates the structured plan.
- Research responses do not create Executive Memory proposals.
- Turning Research Discovery off returns the conversation to normal Executive Team routing without deleting the saved project.

INSTALL
1. Stop backend and frontend.
2. Copy this ZIP’s backend and frontend folders over the project root; replace matching files.
3. From the project root, clean temporary caches:

   Remove-Item -Recurse -Force .\frontend\.next -ErrorAction SilentlyContinue
   Get-ChildItem .\backend -Directory -Recurse -Filter "__pycache__" | Remove-Item -Recurse -Force
   Remove-Item -Recurse -Force .\.pytest_cache -ErrorAction SilentlyContinue

4. Backend terminal:

   cd backend
   .\.venv\Scripts\Activate
   uvicorn app.main:app --reload

5. Frontend terminal:

   cd frontend
   npm run dev

6. Hard-refresh browser with Ctrl+Shift+R and create a new conversation.

PRIMARY TEST
1. Select any workspace. Leave Search All Intelligence OFF and attach no documents.
2. Click “Explore an idea”. The control should display “Research discovery on”.
3. Send: “I have an idea but I’m not sure where to begin.”
4. Expected:
   - response comes from Research Lead;
   - GrowthOS opens a named research project;
   - it explicitly says no complete idea or document is required;
   - it asks adaptive discovery questions;
   - no Executive Memory proposal appears.
5. Reply naturally in one paragraph. Include “not sure” for any unknowns.
6. Expected: GrowthOS records supplied answers and asks only the remaining required questions.
7. Once complete, send: “Build the research plan”.
8. Expected: GrowthOS confirms the plan was created. Open Research to review it.

AUTOMATIC ROUTING TESTS
Without clicking the control, start a new conversation and try:
- “Help me explore a new opportunity.”
- “Research whether opening a private clinic would be viable.”
- “I’m considering a career change but don’t know which direction.”
These should enter discovery automatically.

NORMAL CHAT REGRESSION
With Research Discovery OFF, verify:
- “Hi” gives a natural greeting.
- “Explain SWOT analysis” gives normal executive advice.
- Existing PDF attachment and Search All Intelligence flows still work.
- Background streaming, Stop, inline Edit, Save Memory, and Track Decision still work.

EXIT TEST
During an active research conversation, turn “Research discovery on” OFF and send a normal business question. It should return to ordinary Executive Team routing. The saved research project remains available in Research.
