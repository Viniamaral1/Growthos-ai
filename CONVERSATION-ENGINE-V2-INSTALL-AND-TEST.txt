GrowthOS v4.1 — Conversation Engine V2
======================================

WHAT CHANGED
------------
1. Every message is re-evaluated before guided research continues.
2. Direct tasks such as writing an email interrupt a previous research interview.
3. Research project IDs are no longer displayed in chat replies.
4. Guided discovery asks one focused question at a time with less repetitive wording.
5. When all required discovery answers are available, GrowthOS automatically builds the research plan.
6. The conversation sidebar can be collapsed for focus mode.
7. The composer is smaller and the chat panel uses a fixed working height.
8. Light-mode surfaces have slightly softer contrast.

FILES CHANGED
-------------
backend/app/services/research_project_service.py
backend/app/api/routes/conversations.py
frontend/app/components/CofounderChat.tsx
frontend/app/components/chat/ExecutiveComposer.tsx
frontend/app/globals.css

INSTALL
-------
1. Stop frontend and backend.
2. Replace your current project with this package, or copy the changed files listed above.
3. From frontend:

   npm install

4. From backend, activate your environment and install requirements if needed:

   pip install -r requirements.txt

5. Clear caches:

   Remove-Item -Recurse -Force .\frontend\.next -ErrorAction SilentlyContinue
   Get-ChildItem . -Recurse -Directory -Filter "__pycache__" | Remove-Item -Recurse -Force

6. Start backend first, then frontend.
7. Hard-refresh the browser with Ctrl+Shift+R.
