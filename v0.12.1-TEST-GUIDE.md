# GrowthOS v0.12.1 — Knowledge Extraction + Contradiction Input Quality

## What changed

This patch fixes the upstream issue discovered during Northstar contradiction testing: commercial values could appear inside Source Evidence without becoming structured reusable Knowledge facts.

### Added / improved
- GBP / USD / EUR unit-price extraction from prose such as `GBP 20.10 per carton`.
- Payment-term extraction for wording such as `Payment is due 30 calendar days`, `Payment due 14 days`, and `Net 30`.
- Stable agreement / contract / quotation reference extraction including `Agreement ref NOS-2026-041`.
- Annual quantity extraction for signed scope and planning language.
- Document status extraction such as `SIGNED - CURRENT`, `SUPERSEDED`, `DRAFT`, and `NOT AGREED`.
- Contradiction comparison across separate Knowledge items as well as Knowledge history.
- Guards so superseded evidence and proposal/request language do not automatically become active contradictions.
- Visible project selector on Contradiction Intelligence.
- Safer Knowledge deletion wizard that explicitly preserves the Business Intelligence source.

## Test sequence

Use project **Northstar Office Refresh**.

1. Upload/capture `01_Northstar_Signed_Supply_Agreement.pdf`.
   Expected Knowledge facts include:
   - Premium A4 recycled paper price: GBP 18.40 per carton
   - Payment terms: 30 days
   - Contract / quotation reference: NOS-2026-041
   - Annual quantity: 1,200 cartons
   - Document status: SIGNED - CURRENT

2. Upload/capture `02_Northstar_August_Invoice.pdf`.
   Expected Knowledge facts include:
   - Premium A4 recycled paper price: GBP 20.10 per carton
   - Payment terms: 14 days
   - Contract / quotation reference: NOS-2026-041

3. Open **Contradictions**, select **Northstar Office Refresh**, and run review.
   Expected:
   - Price contradiction: GBP 18.40 vs GBP 20.10
   - Payment-term contradiction: 30 days vs 14 days
   - Both source documents shown.

4. Upload/capture `03_Northstar_Internal_Meeting_Request.pdf` and run review.
   Expected: the request for 60-day terms should NOT become a definite active contradiction because the source explicitly says it was requested / not accepted.

5. Upload/capture `04_Northstar_Quote_v1_Historical.pdf` and run review.
   Expected: the superseded quote remains historical context and should not create a current contradiction merely because values differ.

6. Upload/capture `05_Northstar_Scope_Plan.pdf` and `06_Northstar_Signed_Scope.pdf`.
   Expected Knowledge facts:
   - Plan: Annual quantity 1,500 cartons
   - Signed scope: Annual quantity 1,200 cartons
   Run contradiction review and inspect the scope/quantity conflict.

7. Duplicate lifecycle test:
   - Deliberately capture one Knowledge fact twice after accepting the existing duplicate warning.
   - Open the duplicate Knowledge item and click Delete.
   Expected: a lifecycle-style dialog explains that only the Knowledge item will be removed and the Business Intelligence source remains.

8. Regression:
   - Opportunity Intelligence still loads and behaves as v0.11.8.
   - Knowledge project switching remains stable.
   - No React render-loop or duplicate-key warnings.

## Important interpretation rule

A different value is not automatically a contradiction. GrowthOS should distinguish:
- active authoritative conflicts,
- historical/superseded values,
- proposals or requests,
- ordinary business changes.
